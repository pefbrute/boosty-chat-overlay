# Boosty Chat Overlay

Локальный прототип вывода Boosty-чата в OBS. Пароли и cookies Boosty никуда не отправляются:
страница Boosty остаётся открытой в обычном браузере, а расширение передаёт новые сообщения
локальному серверу на `127.0.0.1`.

## Настольное приложение

Пользовательская версия запускается обычным приложением и сама поднимает локальный сервер.
Она показывает состояние расширения и оверлея и через OBS WebSocket создаёт или обновляет
Browser Source `Boosty Chat` только в явно выбранной пользователем сцене.

Подробный актуальный статус, ограничения и roadmap находятся в
[`PROJECT_STATUS.md`](PROJECT_STATUS.md).

Для разработки:

```bash
npm start
```

Сборка Linux AppImage:

```bash
npm run dist -- --linux AppImage
```

## Поддерживаемые браузеры

- **Яндекс Браузер** (officially verified / подтверждён)
- **Brave** (подтверждён)
- **Google Chrome** (подтверждён)
- **Microsoft Edge** (подтверждён)

Для всех браузеров доступен пошаговый мастер подключения распакованного расширения прямо в приложении при первом запуске (`Fresh onboarding`).

## Быстрый тест оверлея

```bash
npm run start:server
```

Открыть `http://127.0.0.1:17369/overlay/`, затем в другой вкладке открыть
`http://127.0.0.1:17369/test`. В оверлее появится тестовое сообщение.

## OBS

Добавить источник **Browser / Браузер**, URL:

```text
http://127.0.0.1:17369/overlay/
```

Рекомендуемый размер: 900×700.

## Текущий статус

- локальный сервер и прозрачный оверлей готовы;
- тестовые сообщения готовы;
- Chrome-расширение извлекает автора, текст и аватар из реального Boosty-чата;
- приложение определяет heartbeat расширения;
- сервер и расширение подавляют повторы;
- OBS Browser Source добавляется автоматически через локальный OBS WebSocket;
- следующий шаг для массового распространения: публикация расширения в магазинах браузеров.

## Безопасность и доверие

- **Открытый исходный код:** Проект полностью открыт, исходники доступны в публичном репозитории на GitHub.
- **Локальная архитектура (Local-First):** Приложение, расширение браузера и OBS Studio взаимодействуют строго через `127.0.0.1:17369` и локальный порт OBS WebSocket `127.0.0.1:4455`. Сообщения чата, авторизационные куки и личные данные стримера не передаются на внешние серверы.
- **Внешние сетевые подключения:** Единственный внешний запрос — периодическая проверка наличия новой версии через официальный публичный GitHub Releases API (`api.github.com/repos/pefbrute/boosty-chat-overlay/releases/latest`). Телеметрия и сторонние трекеры отсутствуют.
- **Проверка целостности и хеши (SHA-256):** К каждому релизу на GitHub прикладывается файл контрольных сумм `SHA256SUMS.txt`. Проверить скачанный установщик можно локально:
  \`\`\`bash
  # Linux
  sha256sum "Boosty Chat Overlay Setup *.exe"

  # Windows (PowerShell)
  Get-FileHash ".\Boosty Chat Overlay Setup *.exe" -Algorithm SHA256
  \`\`\`
- **Цифровая подпись и SmartScreen:** Сборки собираются прозрачно на GitHub Actions. До оформления официального сертификата разработчика Windows SmartScreen может показывать стандартное информационное окно неизвестного издателя («Система Windows защитила ваш компьютер»). Рекомендуется сверять контрольную сумму файла перед установкой.
