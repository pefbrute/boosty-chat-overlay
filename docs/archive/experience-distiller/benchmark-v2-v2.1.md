## 2. Качественные различия в анализе причин (RCA)

### Пример 1. Git Diff Whitespace Errors (`opp-rout-git_diff_whitespace_check_failed`)
- **Подход v2 (Regex):**
  Увидел строку `blank line at EOF` $\rightarrow$ сформировал рекомендацию: «добавить очистку trailing newline в pre-commit». Без понимания, почему агент не смог исправить это сразу.
- **Подход v2.1 (Level B LLM Reasoner):**
  Выявил, что агент тратит от 2 до 5 ходов, потому что не видит невидимые пробелы в консоли и пытается править файл через `replace_file_content` наугад. Предложил детерминированный CLI-нормализатор `autofix-whitespace.js`, подготовил unit-тест и подтвердил ускорение на 99.89%.

### Пример 2. Windows VM Guest Additions (`opp-rout-virtualbox_guestcontrol_vm_sync`)
- **Подход v2 (Regex):**
  Создал 4 разрозненные записи: ошибку `winda.sh code 33`, ошибку `winda.sh code 52`, общую рутину VirtualBox и скрипт синхронизации.
- **Подход v2.1 (Level B LLM Reasoner):**
  Объединил все 4 симптома в единую корневую причину: вызов команд внутри ВМ до инициализации службы `VBoxGuestAdditions`. Предложил проверку статуса ВМ с backoff-повторами.
