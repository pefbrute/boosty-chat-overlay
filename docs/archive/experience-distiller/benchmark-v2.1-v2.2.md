# Сравнительный бенчмарк: Experience Distiller v2.1 vs v2.2

## 1. Архитектурное сравнение возможностей

| Критерий | Experience Distiller v2.1 | Experience Distiller v2.2 (Текущий релиз) |
|---|:---:|:---:|
| **Генерация решений (Builder)** | Жестко зашитые строковые шаблоны (`autofix-whitespace.js`, `check-env.js`) | **Универсальная оркестрация** без жестко зашитых решений, произвольные типы находок |
| **Жизненный цикл улучшений** | Базовый `propose` / `staging` | **Полный 7-фазный цикл**: `Discover → Explain → Plan → Implement → Test → Evaluate → Review` |
| **Validation Gate** | Ручной вызов проверок | **Независимый шлюз**: синтаксис (Node, Py, Bash, JSON), секреты, авто-запуск тестов, diff |
| **Методология бенчмаркинга** | Одиночные замеры, сравнение ручной оценки (45s) со скриптом (0.05s) | **Научный Anti-Fake Benchmarking**: n $\ge$ 5, медиана + разброс, строгое разделение `measured` / `observed` |
| **Обработка контекста LLM** | Единый монолитный пакет (`llm_packet.json`) | **Пакетная обработка (`batching`)** с трекером состояния (`llm_state.json`) и возобновлением |
| **Переносимость тестов** | Зависимость от локального скилла `windows-qa-winda` | **100% переносимые тесты** с временными изолированными фикстурами |
| **Покрытие тест-сьюта** | 25 тестов | **33 теста** (+8 новых тестов на цикл v2.2, бенчмарки, ошибки) |

## 2. Сравнение объективности измерений

### Недостаток v2.1:
В версии v2.1 зафиксированное ускорение для `opp-rout-git_diff_whitespace_check_failed` сравнивало:
- Предположительное время ручной правки: `45.0 с`;
- Измеренное машинное время скрипта: `0.05 с`;
- Результат: заявлялось «ускорение на 99.89% [measured]».
Это создавало иллюзию машинной точности при сравнении несопоставимых величин.

### Стандарт объективности v2.2:
В версии v2.2 реализован модуль `ObjectiveEvaluator`, который:
1. Замеряет строго эквивалентные машинные процессы на одинаковых входных данных за $\ge 5$ повторов.
2. Для Проблемы 1 (Safe Git Grep) честно зафиксировал:
   - Машинное время: raw `git grep` (`4.45 ms`) быстрее, чем `node safe-git-grep` (`27.67 ms`) из-за накладных расходов запуска Node.js.
   - Система автоматически выставила: `speedup_proven = False`.
3. Сессионная рутина зафиксирована отдельно в категории `observed_session`:
   - Сокращение холостых шагов агента: `3.0` $\to$ `0.0` шагов.
4. Разброс (min, max, standard deviation) теперь всегда сохраняется в метаданных реестра.
