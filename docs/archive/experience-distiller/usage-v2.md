# Руководство пользователя: Experience Distiller v2 (`usage-v2.md`)

## 1. Установка и запуск

Утилита доступна как глобальная CLI команда:
```bash
experience-distiller --help
```

---

## 2. Основные рабочие сценарии

### Сценарий 1. Глубокий семантический анализ истории разработки
Используется для исследования последних сессий и автоматической реконструкции цепочек сбоев:
```bash
# Анализ последних 50 сессий во всех проектах
experience-distiller analyze --recent 50

# Анализ конкретного проекта
experience-distiller analyze --project boosty-chat-overlay --recent 20

# Полный анализ всех доступных сессий без ограничений
experience-distiller analyze --all-projects
```

**Вывод покажет:**
- Число обработанных сессий и охваченных проектов;
- Количество реконструированных цепочек событий (Error Chains);
- Суммарное количество потраченных вхолостую шагов (Toil / Wasted Steps);
- Топ-5 приоритетных возможностей.

---

### Сценарий 2. Просмотр и фильтрация реестра возможностей
```bash
# Вывести топ-20 возможностей
experience-distiller opportunities --top 20

# Фильтрация по минимальному приоритету (например, только высокий приоритет >= 85)
experience-distiller opportunities --min-priority 85

# Фильтрация по категории (routine, error, knowledge, qa, decision)
experience-distiller opportunities --category routine
```

---

### Сценарий 3. Root Cause Analysis (RCA) и объяснение цепочки
Для глубокого понимания, почему возникла проблема и как она решалась в реальных сессиях:
```bash
experience-distiller explain opp-rout-virtualbox_guestcontrol_vm_sync
```

Команда выведет:
1. Точную формулировку первопричины (Root Cause);
2. Историю цепочек событий по каждой сессии (начальное действие $\rightarrow$ сигнатура $\rightarrow$ число попыток $\rightarrow$ исправление $\rightarrow$ верификация);
3. Рекомендуемую архитектуру решения;
4. Оценённые альтернативы.

---

### Сценарий 4. Поиск кросс-проектных синергий
Для выявления проблем, с которыми агент сталкивается сразу в нескольких проектах:
```bash
experience-distiller cross-project
```

Позволяет создавать глобальные решения (в `~/.gemini/config/skills/`), экономящие время сразу для всей экосистемы разработчика.

---

### Сценарий 5. Аудит эффективности существующих скиллов
Проверка, есть ли в системе скиллы, которые должны были предотвратить возникшие ошибки, но не сработали:
```bash
experience-distiller audit-skills
```

Показывает:
- Установленные скиллы;
- Ошибки, произошедшие в предметной области этих скиллов;
- Рекомендации по дополнению скиллов новыми инвариантами.

---

### Сценарий 6. Измерение фактически достигнутой пользы (Feedback Loop)
После внедрения скрипта или обновления скилла зафиксируйте реальный эффект:
```bash
experience-distiller measure opp-qa-multi-step-test-verification-gate \
  --actual "Снизило время полного префлайта с 45 сек до 12 сек и исключило ручные пропуски"
```
Статус возможности автоматически перейдёт в `validated`, а измеренная польза сохранится в реестре.

---

### Сценарий 7. Генерация проекта реализации (Propose) и валидация
```bash
# Сформировать код скрипта или структуру SKILL.md
experience-distiller propose opp-rout-git_diff_whitespace_check_failed

# Проверить созданный инструмент перед коммитом
experience-distiller validate scripts/verify-preflight.js
```

---

### Сценарий 8. Формирование аналитического отчёта
```bash
experience-distiller report --output experience-report-v2.md
```
Создаёт подробный отчёт в формате Markdown со сводными метриками, таблицей топ-20, глубоким RCA, кросс-проектным анализом и дорожной картой внедрения.
